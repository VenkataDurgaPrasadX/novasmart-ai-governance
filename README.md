## Governance Findings & Remediations

1. **Identity & Access Management**: Removed `roles/owner` from shared agent identities. Each agent now executes under its own dedicated service account.
2. **Perimeter Defense**: Model Armor filters prompt injection attempts at the API Gateway level.
3. **Model Safety**: Evaluated agent prompt logic locally, uncovering latent backdoor rules (`NVST-PRICING-7741`). Wrote a local prompt fix and verified reasoning improvement across 7 scenarios.
